# QTTabBar Native Enhanced 1.5.69.0 Stable

This final compatibility attempt removes two differences exposed by the successful
renderer diagnostics and comparison with the reference Explorer background hook.

## Changes

- Keeps background-only mode out of the legacy ShellBrowser-hook path
- Patches only `FillRect` and `CreateCompatibleDC` imports in `dui70.dll`
- Removes the extra `DeleteDC` patch
- Bounds and refreshes compatible-DC mappings without intercepting DC destruction
- Preserves WIC decoding and detailed initialization-phase diagnostics

## Installation

Run the setup executable as administrator and restart Windows when requested. This
release targets Windows 10 x64 and .NET Framework 4.8.
