# QTTabBar Native Enhanced 1.5.66.0 Stable

This compatibility release hardens Explorer background initialization for later Windows 10 22H2 servicing builds.

## Changes

- Validates every `dui70.dll` PE import descriptor and thunk before access
- Bounds import-name scans to the loaded module image
- Converts native parser and IAT access faults into HRESULT diagnostics
- Separates image-renderer startup from scoped-hook activation in the log
- Keeps Explorer operational if a serviced `dui70.dll` layout is unsupported
- Continues to leave the legacy monolithic hook library unloaded by default

## Installation

Run the setup executable as administrator and restart Windows when requested. This release targets Windows 10 x64 and .NET Framework 4.8.
