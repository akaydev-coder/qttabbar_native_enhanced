# QTTabBar Native Enhanced 1.5.68.0 Stable

This compatibility release removes the remaining platform-dependent operation from
Explorer background renderer construction and makes guarded initialization failures
phase-identifiable.

## Changes

- Replaces `std::random_device` with a deterministic visual-selection seed
- Records each renderer initialization phase in lock-free native state
- Logs whether a failure occurred during configuration, WIC decode, DIB creation,
  pixel copying, or final state commit
- Preserves the WIC image decoder and scoped `dui70.dll` hooks

## Installation

Run the setup executable as administrator and restart Windows when requested. This
release targets Windows 10 x64 and .NET Framework 4.8.
