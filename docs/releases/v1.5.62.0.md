# QTTabBar Native Enhanced 1.5.62.0 Stable

This is the first stable release of the consolidated QTTabBar Native Enhanced code line.

## Included

- Stable QTTabBar and QT Button Bar integration
- Restored QT Command Bar (vertical) / Versatile Bar
- Fluent Glass tab and vertical-bar rendering
- Per-tab taskbar thumbnails and full-size previews
- Taskbar thumbnail close support
- Custom tab and new-tab button graphics
- Isolated Explorer background-image rendering
- Options, persistence, focus and registration fixes

## Installation

Run the attached setup executable as administrator and restart Windows when requested. This release targets Windows 10 x64 and .NET Framework 4.8.
