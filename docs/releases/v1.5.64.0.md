# QTTabBar Native Enhanced 1.5.64.0 Stable

This maintenance release replaces the crash-prone Explorer background-image path with a module-scoped renderer.

## Changes

- Removes MinHook from background-only initialization
- Patches only `FillRect`, `CreateCompatibleDC` and `DeleteDC` imports in `dui70.dll`
- Chains through pre-existing API hooks instead of replacing them
- Tracks only explicitly registered Explorer `DirectUIHWND` folder views
- Uses premultiplied 32-bit alpha rendering for PNG/BMP/JPEG files
- Supports image folders, random image selection and path-specific profiles
- Reloads valid configuration changes without exposing partial renderer state
- Uses window-property tokens to reject stale or reused window handles
- Keeps the legacy process-wide Shell hook path disabled by default
- Allows holding Escape during Explorer startup to bypass background initialization

## Installation

Run the setup executable as administrator and restart Windows when requested. This release targets Windows 10 x64 and .NET Framework 4.8.
