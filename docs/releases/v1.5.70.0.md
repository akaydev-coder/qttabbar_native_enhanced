# QTTabBar Native Enhanced 1.5.70.0 Stable

This release completes the stable background renderer path by providing the paint-DC
association used by the reference implementation without introducing a global hook.

## Changes

- Patches `BeginPaint` only in `ExplorerFrame.dll`
- Associates the resulting HDC with registered `DirectUIHWND` file views
- Keeps drawing hooks scoped to `dui70.dll`
- Does not restore the removed `DeleteDC` interception

## Installation

Run the setup executable as administrator and restart Windows when requested. This
release targets Windows 10 x64 and .NET Framework 4.8.
