# QTTabBar Native Enhanced 1.5.67.0 Stable

This compatibility release replaces the Explorer background image decoder after isolating an access violation to the renderer stage on a later Windows 10 22H2 servicing build.

## Changes

- Uses Windows Imaging Component instead of GDI+ for PNG/BMP/JPEG decoding
- Produces premultiplied `32bppPBGRA` pixels directly in the renderer DIB
- Removes raw bitmap stride traversal from Explorer startup
- Preserves phased renderer and scoped-hook diagnostics
- Keeps validated `dui70.dll` imports and legacy-hook isolation

## Installation

Run the setup executable as administrator and restart Windows when requested. This release targets Windows 10 x64 and .NET Framework 4.8.
