# QTTabBar Native Enhanced 1.5.65.0 Stable

This compatibility release removes the legacy hook library from the normal Explorer-background startup path.

## Changes

- Hosts the Explorer background renderer directly in `QTTabBarNative.dll`
- Does not load `QTHookLib32.dll` or `QTHookLib64.dll` when only background images are enabled
- Keeps legacy Shell hooks available only when `[hook] enabled=true` is explicitly configured
- Retains the three scoped `dui70.dll` imports and registered-window filtering
- Preserves PNG/BMP/JPEG alpha rendering, image folders, random selection and path profiles
- Keeps Escape startup recovery for problematic configurations

## Installation

Run the setup executable as administrator and restart Windows when requested. This release targets Windows 10 x64 and .NET Framework 4.8.
